# Flitsvis V3

Visueel, vrijwel tekstloos flitsspel voor groep 1-2. Leerdoel: hoeveelheden t/m 6 direct herkennen zonder één-voor-één te tellen.

## V3
- geïllustreerde WebP-spelwereld;
- kindkant vrijwel tekstloos;
- gesproken Nederlandse aanwijzingen;
- start 1-3 en adaptief naar 4 en 6;
- plusniveau 7-9 alleen als leerkracht dit toestaat;
- één gestructureerde herkansing na een fout;
- fysieke Marbotic-cijfers via lokale 3-puntskalibratie;
- mobiele knoppen worden niet meer door de Marbotic-touchlistener geblokkeerd;
- totale illustratie-assets circa 0,15 MB.

## Test na publicatie
1. Open op iPhone/Android en iPad: startknop moet direct reageren.
2. Controleer dat de hoeveelheid verdwijnt vóór antwoorden mogelijk is.
3. Speel vier eerste antwoorden goed en controleer adaptieve verhoging.
4. Geef een fout antwoord en controleer de gestructureerde herkansing.
5. Test leerkrachtinstellingen en resultaten.
6. Kalibreer Marbotic op een echte iPad en test fysieke cijfers.
